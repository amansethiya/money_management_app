# ₹ TRACASH - Cash Tracker

A simple Expense & Income Tracker built using **React + Tailwind CSS**.

## 🚀 Features

- Add Income & Expenses
- Track total income & expenses
- Clean UI dashboard
- Transaction table

## ⚙️ Tech Stack

- React
- Tailwind CSS
- Vite
